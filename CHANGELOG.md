# Changelog

All notable changes to this project. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/).

## [2.0.0] - 2026-11-27

### Added
- **`delegate` engine**: a stdlib-only Python CLI that Claude calls. Commands: `doctor`, `init`, `task new`, `scope add`, `work`, `verify`, `review`, `triage`, `status`, `approve`, `done`, `abandon`, `report`.
- **Evidence-based gates**: every gate result and review round is tied to the sha256 of the scoped diff, so a missing, stale, failed or timed-out check never counts as a pass.
- **Risk tiers** (low / medium / high) that decide what `done` requires. High-risk changes (auth, migrations, billing, CI, dependency manifests, test and lint config, `delegate.toml`) need both reviewers and a human approval.
- **Human-only `approve`**: requires a real interactive console. Windows `NUL` stdin is rejected even though it reports as a tty.
- **Goldfish reviews**: Codex (read-only) and Gemini via `agy` (plan mode) review in parallel with fresh context. Output is checked for the right format, invalid output gets one retry, and the 3-round cap counts only rounds where a reviewer actually ran.
- **Secret scan** before anything leaves the machine (private keys, AWS/OpenAI/GitHub/Google keys, JWTs, credential assignments, `.env` files), plus `gitleaks` when it's installed.
- **Protecting your work**: your uncommitted edits are snapshotted and never sent; lockfiles are left out of review diffs; workers can't forge other tasks' state in `.delegate/`.
- **Timeouts with process-tree kill** (`taskkill /T` on Windows, process groups on POSIX).
- **Metrics**: one JSON line per finished task (counts only, no code), summarized by `delegate report`.
- Project site (`docs/index.html`), CI on Windows, Linux and macOS × Python 3.11–3.13, and README visuals generated by `scripts/make_visuals.py`.

### Changed
- `SKILL.md` now drives the CLI. The v1 manual recipes moved to `docs/manual.md` as a fallback.

### Fixed (found in the first real-CLI run)
- `agy` couldn't read briefs inside the git-excluded `.delegate/` folder. Review files now go through a temp folder outside the repo.
- `agy` resolved relative paths against the brief's folder. Changed files are now listed with full paths.
- `agy` auto-loads its own skills, so its skills folder is now readable. Plan mode stays read-only.
- Windows piped output (cp1252) crashed on the finding icons. Output is now UTF-8.

## [1.0.0] - 2026-11-18

### Added
- The `delegate` Claude Code skill: prompt-only orchestration of Codex (worker) and Gemini via `agy` (reviewer) on existing subscriptions, plus the goldfish review loop borrowed from [google/elephant-goldfish-model](https://github.com/google/elephant-goldfish-model).
