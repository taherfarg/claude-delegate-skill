Benefits

Save Claude limits

Give implementation to Codex. Keep Claude’s budget for planning and decisions.

Get two second opinions

Codex and Gemini review with fresh context and catch blind spots in the diff.

Finish reviews faster

Both reviewers read the same patch in parallel, so neither waits for the other.

Meet the models

Orchestrator

Claude

The elephant holds the project context. It writes the brief, checks the diff, and decides how to handle each finding.

Worker + reviewer

Codex

ChatGPT writes code through the Codex CLI. For review, it returns as a goldfish with a fresh context and no chat history.

Researcher + reviewer

Gemini

Gemini researches through the Antigravity CLI (agy). As the second goldfish, it reviews the diff independently of the conversation.

How it works

  1. 1

    Write the brief

    Claude turns the task and its constraints into a brief for Codex.

  2. 2

    Build in a sandbox

    Codex implements the brief in a sandbox and returns a patch.

  3. 3

    Verify the diff

    Claude checks the changes against the brief and runs the tests.

  4. 4

    Review in parallel

    Codex and Gemini report each blocker, major issue, or nit with a file:line reference.

  5. 5

    Resolve and repeat

    Claude fixes or contests every finding. Stop after one clean round or three rounds total.

Review loop

Each goldfish gets the diff with no chat history. Findings point Claude to a specific line and explain what needs attention.

  • Blockerexport.ts:12

    The export includes rows from another account.

  • Majorcsv.ts:24

    Escape quotes inside fields so the CSV parses correctly.

  • Nitcsv.ts:31

    Rename buf to csvRow to clarify what it holds.

Install delegate

Clone the skill into your Claude Code skills directory, then install the delegate engine from that same folder, so one git pull updates both.

git clone https://github.com/taherfarg/claude-delegate-skill ~/.claude/skills/delegate
pip install --user -e ~/.claude/skills/delegate
delegate doctor

macOS, Linux or Git Bash. On Windows PowerShell use "$env:USERPROFILE\.claude\skills\delegate" as the target folder.
